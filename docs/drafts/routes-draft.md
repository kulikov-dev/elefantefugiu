## Что нужно решить (прошу сверки)

1. **Дуги над сушей.** Great-circle для моря даёт линию через сушу: Лиссабон→Рим идёт через Испанию, Индия→Лиссабон через Африку, Мадейра→Гавайи через Америку. Предложение: в данных допустить точки-«формы» без подписи (`shape: true`, например мыс Горн, мыс Доброй Надежды, Гибралтар), всегда с `approx` и пунктиром, не в списке «Точки пути». Это промежуточные точки, которые вы просили не выдумывать, поэтому только с вашего «да» и с проверкой по источнику. Без них — только дуги, чуть выгнутые, где линия идёт по суше (Рим, Специя). Варианты: (а) формы-точки, (б) подписывать «приблизительно» и мириться, (в) отбросить кандидатов 1, 7, 8, 9.
2. **Смешанный тип** (море+суша; суша+река): один `mode` на маршрут или на каждый отрезок? Мне хватает одного на маршрут (по главному отрезку), отрезок можно добавить позже.
3. **Cantino.** Рисуем Лиссабон→Феррара одной приблизительной дугой, без Генуи и Модены? Или две ветки?
4. **Рабелу.** Приемлема ли почти прямая линия по Дору между двумя точками, или без реальной реки карту не делаем?
5. **Ганнон/Каталина/Дом снега** по их неточности: оставляем только Ганнона, остальных два пограничных отбрасываем?
6. **Перелёт 1922.** Остаёмся при трёх точках, или вы дадите промежуточные посадки в текст?
