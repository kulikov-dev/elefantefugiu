# STATE: состояние проекта

Обновлено 28.10.2026. Здесь только текущее состояние. Этапы 1–7 и правки по датам: `docs/history.md` (прежний STATE без изменений). Продукт: `docs/design.md`, `docs/spec.md`; запуск и настройка: `README.md`.

## Версии

- Astro 7.3.8, TypeScript 6, Zod (из `astro/zod`). Node 22 (`.nvmrc`, `engines` ≥ 22.12; workflow берёт версию из `.nvmrc`).
- Leaflet 1.9.4 (без плагина кластеров, кластеры свои: `src/lib/markers.ts`), `tsx` 4.23.15, `yaml` 2.9.1, Vitest 5.0.4: версии закреплены точно.
- `scripts/qa/` (свои зависимости, в сборку не входит): `puppeteer-core` 23.11.1, `@sparticuz/chromium` 131.0.1.
- Шрифты Playfair Display, Source Serif 4, Oswald: Fontsource, самохостинг (латиница и кириллица). Preload только на русских страницах (шесть файлов, `check:ru`); на pt и en его нет, там хватает подогнанных запасных шрифтов (заголовочный Playfair расширен на 2,3% под веса 600–800). Решение 2026-10-28: сдвиг вёрстки на 360 px был 0,17–0,19 на двух ru-страницах, стал около 0.

## Структура

```
src/pages/          index (выбор языка), [lang]/[...page] (главная, служебные), [lang]/[segment]/[slug] (история, эпоха, нить), [lang]/[map], p/[id] (QR-переход), 404

src/content/        events/*.yaml, epochs.yaml, threads.yaml, featured.yaml; схемы в src/data/schemas.ts
src/data/           schemas.ts, static-pages.ts (тексты «О проекте», «Метод», «Правовая»)
src/styles/         tokens.css (все цвета, шрифты, размеры), reset, base, layout, map
tests/              node:test (78) и tests/vitest (236)
scripts/            check-*.mjs/ts (сборка), make-*.mjs, lang-*.ts (вычитка), qa/ (браузерные наборы, 32 набора)
docs/               design.md, spec.md, STATE.md, history.md, glossary.md, language-review/, addresses.md, images/, mascot/
```

**Аналитика.** GoatCounter без cookie, источник визита `?src=` (или синоним `?utm_source=`) уходит как referrer (`r` в запросе count.js, проверено запросом в браузере); с 29.10.2026 `r` уходит только при `src`/`utm_source` или с чужого хоста (свой домен, в том числе `www`, и прямой заход без `r`), `kulikov-dev.github.io` склеен в `old-domain`; свои заходы выключает штатный `#toggle-goatcounter` в `count.js` (флаг `skipgc` в localStorage, показывает alert; описано в README «Analytics»); Campaigns GoatCounter заполняет сам из `campaign`/`utm_campaign` в адресе (имена зашиты в нём, настройки нет), поэтому для кампании дописывается `&campaign=<имя>`, свой код кампанию не добавляет; старые пути `/elefantefugiu/…` в статистике не трогаем; корень `/` и `/p/{id}` при переходе на язык сохраняют query string и hash (раньше терялись, а `?src=qr` на `/p/` затирал чужой `src`); проверка в QA smoke (`pages`), скрипт самохостинг (`public/vendor/goatcounter/count.js`, не минифицирован), `?src=qr` попадает в «Referrers»; на локальных адресах выключена.

## Открытые вопросы и что осталось владельцу

- **Лента эпох на главной, хронология эпохи (31.10.2026).** Лента: скроллбар скрыт с JS, кнопки ‹ › от 768 px (`timeline-nav.ts`), snap, фокус, без JS тонкий скроллбар и постоянное затухание справа; эпохи «Скоро» не уже 10 rem. Хронология: у эпох с направленным узором (`no`, `onda`, `pegada`, `xadrez`) прямая линия убрана, узор стал осью (`--azulejo-opacity-axis: 0.5`); точки цвета эпохи с обводкой цветом фона, мелкие 10 px (в `check:contrast` пара «точка на странице», 3:1); колонка года 5 rem, диапазон не рвётся на тире (`yearParts`), дата до н. э. в две строки. Отметка «прочитано» в карточке без высоты, пока карточка не прочитана: раньше она переносилась на пустую строку (~27 px), если метки занимали всю ширину; у прочитанной карточки с полной строкой меток высота растёт на строку. QA: секция 9b в `controls.mjs`.
- **Эпоха 0 «Пролог: динозавры и камни» (31.10.2026; id и адрес `antes-de-portugal`; даты «150 млн лет — VI в. до н. э.», тема «Следы динозавров, рисунки Коа, кромлехи»; 150 млн лет круглое число внутри поздней юры Лоуриньяна, источники дают 157–145).** В `epochs.yaml` с `order: 0`, `mvp: false`, `placeholder: [theme]`, историй нет: на сайте только плитка «Em breve» первой в ленте. Нумерацию остальных эпох не меняли (`order` только ключ сортировки; тест порядков теперь требует уникальности, а не 1..N). Заготовлены палитры и узоры трёх закрытых эпох: 0 (`pegada`), 2 (`estrela`), 3 (`xadrez`); у направленных узоров (`pegada`, `xadrez`, как `no` и `onda`) есть повёрнутая плитка для вертикальной полосы. Эпоха 9 «Atualidade» палитры и узора пока не имеет. **Задача на потом:** лента внутри эпохи 0 должна идти в миллионах лет. Схема не мешает (`year` целое число, `year_scale` свободный текст), но подписи шкалы и `yearText` рассчитаны на годы нашей эры и «до н. э.»: нужна единица «млн лет» и сжатая шкала.

- Вычитка носителем: списки в `docs/language-review/*.md` («Что показать живому носителю»: pt 32, ru 15, en 12 правок, не применённых по правилам уверенности).
- Ссылки с 403 (защита от ботов; проверить руками): britannica, infopedia ×2, dorotheum, smarthistory, britishmuseum, newcriterion, fandom, visitportugal. Цепочка сертификатов не отдаётся сервером (в Firefox проверить): `dl.uc.pt`, `exercito.pt`, `cloud.theportugalnews.com`, `comerciocomhistoria.gov.pt`. `monumentos.gov.pt` отвечает только по http.
- Настоящие тексты для эпохи Estado Novo и 8 тестовых карточек. **Решение владельца (28.10.2026): тяжёлые темы (16+, нить Memória, очерки о них) не берутся до появления рецензента** (design.md §6.1). Пилот QR-кодов у реальных мест вынесен за рамки MVP, адреса `/p/{id}` остаются.
